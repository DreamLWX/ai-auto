### 2. `schedule.py` 第 48 行 `due_date.hour` 属性错误

```python
hour = task.due_date.hour if hasattr(task.due_date, 'hour') else 12
```

`due_date` 是 `Date` 类型（只有日期，没有时间），不是 `Datetime`。`hasattr(task.due_date, 'hour')` **永远返回 `False`**，`hour` 总是被设为 `12`。

**修复方式**: 由于 tasks 没有具体时间，改用 `task.due_date.weekday()` 作为 day 索引，hour 可以固定为 12 或移除 hour 字段。

## 🟡 P1 - 性能问题

### 3. `models.py` 中 `Trip.is_hidden()` 和 `to_dict()` N+1 查询

每个 trip 的 `is_hidden()` 和 `to_dict()` 都会触发数据库查询：

```python
def is_hidden(self):
    participant_count = TripParticipant.query.filter_by(trip_id=self.id).count()  # DB 查询

def to_dict(self, include_hidden=False):
    'participant_count': TripParticipant.query.filter_by(trip_id=self.id).count()  # 又查一次
```

当渲染行程列表时，100 条行程会产生 200+ 次 DB 查询。

**修复方式**: 在 `trips.py` 列表查询时用 `joinedload` 预加载 TripParticipant，或使用缓存的 participant_count。
